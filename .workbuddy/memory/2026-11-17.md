- 关键坑：Edge headless 复用同一 user-data-dir / 调试端口时，会连上上一次残留的标签页并加载旧 HTML，导致修改后的代码不生效（排查了很久）。必须用**每次唯一的 user-data-dir + 唯一调试端口 + URL 版本号**，并在结束时 `Browser.close`。
- 另一个坑：Node 批量 `fs.unlinkSync` 超过 50 个文件触发 safe-delete 守卫；逐帧渲染改为直接覆盖同名文件，不要先清空目录。
